# Синтетические примеры

Все issue keys, пользователи, даты, refs, хэши source inputs и URLs здесь иллюстративные. Они не указывают на реальные ресурсы и не доказывают выполнение команд. Digest change.plan.json вычислен над его payload; план исторический и не предназначен для apply. Go-инструмент полного pack validation отложен в T-TOOLING. Handoff намеренно не объявляет тесты исполненными. Jira-профиль и response examples относятся к proposed продуктовым командам.
